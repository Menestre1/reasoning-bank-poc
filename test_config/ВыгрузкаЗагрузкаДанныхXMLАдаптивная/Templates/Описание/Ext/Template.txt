
Данная обработка позволяет обмениваться данными между идентичными конфигурациями.
Например выгружать тестовый документ из рабочей базы в базу разработки.

 
Обычная Выгрузка загрузка XML не справляется с данной задачей, так как выдает ошибку
при любых изменениях в метаданных, затрагивающих объекты выгрузки. А в базе разработки
постоянно происходят изменения.

В данной обработке при загрузке лишние реквизиты игнорируются, недостающие оставляются пустыми.


НЕ РЕКОМЕНДУЕТСЯ загружать данные в рабочую базу через данную обработку!

Для избежания случайной загрузки предусмотрен предохранитель на закладке
Загрузка, блокирующий элементы, если есть подозрение, что это рабочая база.
