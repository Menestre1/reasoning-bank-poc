# Команда /search-code

**Назначение:** Выполняет полнотекстовый поиск (Full-Text Search) по загруженной конфигурации 1С. Ищет совпадения в исходном коде модулей.

**Синтаксис:** `/search-code <текст_для_поиска>`

**Примеры:**
- `/search-code ЗапросСобеседника`
- `/search-code ОбработкаСобытий`
- `/search-code РегистрСведений`

**Как это работает:**
1. Поиск идет по индексу, созданному при загрузке конфигурации (`/load-config`)
2. Находит все вхождения текста в коде модулей
3. Возвращает список объектов и методов, где найден текст
4. Можно перейти к конкретному методу через `/explain <Объект.Метод>`

**После поиска можно:**
- Использовать `/explain <Объект.Метод>` для детального анализа найденного кода
- Использовать `/callers <Объект.Метод>` чтобы узнать, кто вызывает этот код
- Использовать `/semantic-search` для поиска по смыслу (а не по тексту)

**Примечание:** Поиск чувствителен к регистру в зависимости от настроек SQLite FTS.
