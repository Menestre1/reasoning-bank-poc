# Команда /extract-my-code

**Назначение:** Извлекает из текстового файла модуля 1С процедуры и функции, содержащие маркеры комментариев (AVS, Космачев). Результат сохраняется в отдельный файл.

**Синтаксис:** `/extract-my-code <входной_файл> [выходной_файл]`

**Примеры:**
- `/extract-my-code ./module.txt`
- `/extract-my-code ./module.txt ./my_procedures.txt`

**Как это работает:**
1. Читает файл модуля 1С (формат .txt с кодом BSL)
2. Ищет процедуры и функции, перед которыми (или внутри которых) есть комментарии с маркерами `AVS` или `Космачев`
3. Извлекает найденные подпрограммы в отдельный файл
4. Сохраняет результат в выходной файл (по умолчанию `extracted_code.txt`)

**Когда использовать:**
- Когда нужно отделить свои процедуры от кода конфигурации
- Для анализа только тех фрагментов, которые вы добавляли/меняли
- При подготовке кода к переносу в другую конфигурацию

**Пример маркированного кода:**
```bsl
// AVS: Добавил проверку уникальности
Процедура ПередЗаписью(Отказ)
    Если НЕ ПроверитьУникальность() Тогда
        Отказ = Истина;
    КонецЕсли;
КонецПроцедуры
```

**После извлечения можно:**
- Использовать `/search-code` для поиска по извлеченному коду
- Использовать `/semantic-search` для поиска по смыслу
- Загрузить извлеченный код как отдельную конфигурацию (`/load-config`)

**Примечание:** Файл должен быть разрешен в переменной `ALLOWED_TOOL_ROOTS`.
