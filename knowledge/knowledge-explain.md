# Команда /explain

**Назначение:** Дает подробное объяснение работы конкретного метода объекта 1С. Показывает код, описывает логику, указывает входные/выходные параметры.

**Синтаксис:** `/explain <Объект.Метод>`

**Примеры:**
- `/explain Документ.ЗаказКлиента.ПередЗаписью`
- `/explain Справочник.Товары.ОбновитьЦены`
- `/explain Отчет.Продажи.Сформировать`

**Как это работает:**
1. После загрузки конфигурации (`/load-config`) система индексирует все модули
2. Команда находит указанный метод в базе
3. Извлекает исходный код метода
4. Отправляет код в LLM для анализа и объяснения
5. Возвращает понятное описание работы метода

**Что включает объяснение:**
- Назначение метода (краткое описание)
- Входные параметры и их типы
- Логика работы (пошагово)
- Вызываемые методы других объектов
- Возвращаемые значения (если есть)
- Возможные побочные эффекты

**После объяснения можно:**
- `/callers <Объект.Метод>` — узнать, кто вызывает этот метод
- `/callees <Объект.Метод>` — узнать, что вызывает этот метод
- `/search-code <запрос>` — найти похожие методы

**Пример использования:**
```
/explain Документ.ЗаказКлиента.ПередЗаписью
```
Система ответит подробным объяснением того, что делает этот обработчик события.

**Примечание:** Метод должен существовать в загруженной конфигурации.
