# Где хранятся модули 1С-конфигурации

После выполнения команды `/load-config <путь>` агент загружает объекты конфигурации (документы, справочники, обработки, общие модули) в таблицу `config_objects`. Текст модулей (BSL-код) сохраняется в поле `module_full` и индексируется через FTS5 (полнотекстовый поиск).

## Как искать код

- **Команда:** `/search-code <слово>`
- **Что ищет:** FTS5 по полям `name` и `module_full`, с fallback на LIKE если FTS5 ничего не нашёл.
- **Пример:** `/search-code транзакция` — найдёт все объекты, содержащие слово «транзакция» в модуле или имени.

**Примечание:** Поиск работает только для конфигураций, загруженных через `/load-config` в текущей сессии (или после перезапуска, если БД не очищена через `/next`).

## Ответы на частые вопросы

**Вопрос:** «Ты добавил этот код в базу пациента?»
**Ответ:** Код из загруженной конфигурации сохраняется в `config_objects`, а не в `patient_knowledge`. Для поиска используйте `/search-code`. Чтобы перенести конкретный модуль в PatientKB, отправьте его текст в чате как код (в ``` блоках) — он сохранится автоматически.

**Вопрос:** «Где искать модули?»
**Ответ:** Используйте `/search-code <запрос>`. Результаты показывают имя объекта и первые 64 слова из модуля.
