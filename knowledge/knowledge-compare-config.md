# Команда /compare-config

**Назначение:** Сравнивает две конфигурации 1С и показывает различия между ними. Помогает понять, что изменилось между версиями.

**Синтаксис:** `/compare-config <путь_к_старой> <путь_к_новой>`

**Пример:** `/compare-config ./config_v1 ./config_v2`

**Что делает команда:**
1. Загружает обе конфигурации (старую и новую)
2. Сравнивает структуру объектов, модули, макеты
3. Находит добавленные, удаленные и измененные объекты
4. Создает отчет о различиях

**После сравнения можно:**
- `/comparison-summary` — получить краткую сводку изменений
- `/diff-module <объект>` — посмотреть детальный diff конкретного модуля
- `/changed-objects [тип]` — список измененных объектов определенного типа

**Пример использования:**
```
/compare-config C:\configs\old C:\configs\new
/changed-objects Справочник
/diff-module Документ.ЗаказКлиента
```

**Примечание:** Обе папки должны быть разрешены в `ALLOWED_CONFIG_ROOTS`.
