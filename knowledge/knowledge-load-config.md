# Команда /load-config

**Назначение:** Загружает выгрузку конфигурации 1С из указанной папки, индексирует все XML-файлы, извлекает модули и сохраняет их в базу данных для последующего поиска и анализа.

**Синтаксис:** `/load-config <путь_к_папке_с_выгрузкой>`

**Пример:** `/load-config ./my_config`

**Что делает команда:**
1. Сканирует указанную папку на наличие XML-файлов конфигурации
2. Парсит структуру конфигурации (формы, модули, макеты)
3. Извлекает исходный код модулей (1С:BSL)
4. Сохраняет всё в векторную базу данных для семантического поиска

**После выполнения можно использовать:**
- `/search-code <запрос>` — поиск фрагментов кода по ключевым словам
- `/semantic-search <описание>` — семантический поиск (по смыслу)
- `/build-graph` — построение графа вызовов между объектами
- `/explain <Объект.Метод>` — объяснение работы конкретного метода

**Примечание:** Папка должна быть разрешена в переменной окружения `ALLOWED_CONFIG_ROOTS`.  
Пример: `ALLOWED_CONFIG_ROOTS=C:\configs,D:\1C-configs`
