# Команда /build-graph

**Назначение:** Строит граф вызовов между объектами и методами загруженной конфигурации 1С. Помогает понять архитектуру и найти циклические зависимости.

**Синтаксис:** `/build-graph`

**Что делает команда:**
1. Анализирует все модули загруженной конфигурации
2. Выявляет вызовы методов других объектов (через `Объект.Метод()` или `Выполнить()`)
3. Строит ориентированный граф зависимостей
4. Сохраняет граф в форматах GraphML (для визуализации) и JSON (для анализа)

**После построения графа можно:**
- `/callers <Объект.Метод>` — найти все методы, которые вызывают указанный
- `/callees <Объект.Метод>` — найти все методы, которые вызываются из указанного
- `/cycles` — найти циклы в графе (частая причина ошибок)
- `/graph-viz [объект]` — экспортировать граф для визуализации (yEd, Gephi)

**Пример использования:**
```
/build-graph
/callers Документ.ЗаказКлиента.ПередЗаписью
```

**Примечание:** Граф строится только после загрузки конфигурации через `/load-config`.
