# Доступные инструменты Лиря

## Работа с конфигурацией
- `/load-config <путь>` — загрузить конфигурацию 1С из файла или папки. После загрузки станут доступны команды анализа кода.
- `/search-code <запрос>` — поиск по коду (полнотекстовый поиск). Ищет по всем модулям загруженной конфигурации.
- `/semantic-search <запрос>` — семантический поиск по коду. Находит похожие по смыслу фрагменты.
- `/auto-search on|off` — включить/отключить автоматический семантический поиск. При включённом (по умолчанию) код-запросы автоматически ищут релевантные модули без ручного `/search-code`.
 
## Производительность
- `/load-measurements <путь>` — загрузить замеры производительности (файл .xml).
- `/top-slow [лимит] [объект]` — показать топ медленных объектов. По умолчанию лимит 20.
- `/explain-slow <объект>` — подробный анализ медленного объекта с рекомендациями.

## Графы и зависимости
- `/build-graph` — построить граф вызовов и зависимостей конфигурации.
- `/callers <Объект.Метод>` — показать, кто вызывает указанный метод.
- `/callees <Объект.Метод>` — показать, что вызывает указанный метод.
- `/cycles` — найти циклы зависимостей в коде.
- `/graph-viz [объект]` — экспортировать граф в формате GraphML для визуализации в yEd, Gephi.

## Сравнение конфигураций
- `/compare-config <старая> <новая>` — сравнить две конфигурации и найти отличия.
- `/comparison-summary` — сводка по последнему сравнению.
- `/diff-module <объект>` — подробный diff конкретного модуля.
- `/changed-objects [тип]` — список изменённых объектов (можно фильтровать по типу).

## Анализ кода
- `/explain <Объект.Метод>` — объяснение работы метода на русском языке.
- `/extract-my-code <вход> [выход]` — извлечь код 1С из файла (например, из .txt с кодом).

## Как пользоваться
Для выполнения команды просто введите её с параметрами. Например:
- `/load-config C:\Configs\MyConfig` — загрузить конфигурацию из папки
- `/search-code "проведение документа"` — найти код, связанный с проведением
- `/explain Документ.Реализация.Проведение` — узнать, что делает метод проведения

Если вы не знаете точное название команды, просто опишите, что хотите сделать — я подскажу подходящую команду.
