# Инструмент: extract-my-code

## Назначение

Выделяет из текста модуля 1С только те подпрограммы (процедуры и функции), в которых или перед которыми встречаются комментарии, содержащие заданные маркеры.  
Позволяет отделить авторский код от типового и сгенерированного.

## Как использовать

```bash
python tools/extract_my_code.py --input <файл> --output <файл_результата> --markers AVS Космачев
```

Если `--output` не указан, результат пишется в `2.txt`.

## Интеграция с агентом

В агенте Лирь команда:  
`/extract-my-code <input_file> [output_file]`

Запускает скрипт и возвращает путь к результату.

## Пример диалога

### Для extract-my-code:
Пользователь: `/extract-my-code ./1.txt ./my_code.txt`  
Агент: Запускаю извлечение... Найдено 6 подпрограмм. Результат сохранён в ./my_code.txt

### Для load-config (загрузка конфигурации 1С):
Пользователь: «Мне нужно проанализировать конфигурацию 1С»
Агент: Для анализа конфигурации 1С используйте: `/load-config <путь_к_папке>`

Пользователь: «Ты можешь открыть файл с диска?»
Агент: Нет, у меня нет прямого доступа к вашему диску. 
Для работы с конфигурацией 1С используйте:
1. `/load-config C:\1C\ConfigExport` — загрузить конфигурацию
2. `/extract-my-code файл.txt результат.txt` — извлечь ваш код

## Контекст и сценарии использования

### Почему нет прямого доступа к диску?
У агента Лирь нет прямого доступа к локальной файловой системе пользователя. Это ограничение безопасности.

### Как объяснять пользователю?
Когда пользователь спрашивает: "Ты можешь считать файл с диска?", "Посмотри файл 1.txt" — отвечай:
1. **Нет прямого доступа** — "У меня нет прямого доступа к вашему диску"
2. **Как загрузить** — "Пожалуйста, загрузите файл в чат или укажите путь"
3. **Какой инструмент использовать** — "Используйте `/extract-my-code <файл> [выходной_файл]`"

### Когда какой инструмент использовать?

| Ситуация | Инструмент | Пример |
|-----------|-----------|--------|
| Нужно проанализировать конфигурацию 1С (все модули) | `/load-config <путь_к_папке>` | `/load-config C:\1C\ConfigExport` |
| Нужно извлечь только свой код из одного модуля | `/extract-my-code <файл> [выходной]` | `/extract-my-code 1.txt 2.txt` |
| Хочу узнать, как работает функция | `/explain Объект.Метод` | `/explain Документ.Заказ.ПередЗаписью` |

### Примеры диалога:

**Вопрос:** "Ты имеешь доступ к файловой системе?"
**Ответ:** "Нет, у меня нет прямого доступа к вашей файловой системе. Я могу работать только с теми файлами, которые вы загрузите в наш чат.

**Доступные инструменты:**
1. `/load-config <путь>` — загрузить конфигурацию 1С для анализа
2. `/extract-my-code <файл> [выходной]` — извлечь ваш код из модуля
3. `/explain Объект.Метод` — объяснить работу функции"

**Вопрос:** "Посмотри файл 1.txt"
**Ответ:** "Я не имею прямого доступа к файлам на вашем компьютере. Чтобы я мог извлечь код, пожалуйста, используйте команду `/extract-my-code 1.txt 2.txt`"

**Вопрос:** "Мне нужно проанализировать конфигурацию 1С"
**Ответ:** "Для анализа конфигурации 1С используйте: `/load-config <путь_к_папке>`\nПример: `/load-config C:\1C\ConfigExport`"

**Вопрос:** "Как работает транзакция в 1С?"
**Ответ:** Объяснение, затем подсказка: "Если нужно извлечь ваш код из модуля, используйте `/extract-my-code <файл>`"
